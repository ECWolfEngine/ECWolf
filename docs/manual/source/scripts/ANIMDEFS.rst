ANIMDEFS
========

ANIMDEFS allows animation to be assigned to textures. Animations can either be looping sequences, switches, or even warping. This is implemented as shared code from ZDoom, so see the :zd:`ANIMDEFS` page on the ZDoom wiki for more documentation. At this time, animated doors and camera textures are not used.
