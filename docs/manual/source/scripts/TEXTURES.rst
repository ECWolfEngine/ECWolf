TEXTURES
========

The textures lump is used to define composited textures. The lump is supported by code from ZDoom and should be mostly identical to :zd:`ZDoom's TEXTURES <TEXTURES>` lump (note that the deprecated features have been removed).

One additional feature is the ability to assign textures to art indexes for art screens. It is not recommended that you use this feature since graphics can be given by name. The syntax is "**artindex** *number*, *texture*".
