.. decorate-actor-header:: SpearOfDestiny

Overview
--------

The objective of the game Spear of Destiny. This item, when picked up, freezes the player and plays the pickup sound. After the sound plays the Pickup state is run. It is similar to :class:`CustomInventory` in that sense, but the state is actually shown and not simply executed.
