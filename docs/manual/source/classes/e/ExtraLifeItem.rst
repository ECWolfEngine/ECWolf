.. decorate-actor-header:: ExtraLifeItem

Overview
--------

The base class for "extra life" items, which grant an extra life on reaching the max amount. After that, the amount is reset to zero, being ready to award another extra life. This works similarly to :class:`Ammo` where each child of this class is a kind, and each child of that kind are alternative pickups for that kind.
